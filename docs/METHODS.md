# TP53 统一研究评估 v0.4.0

本版把逐来源画像推进为分层的描述性研究指数，同时保留原值、来源差异与缺失。它是本项目提出的汇总规则，尚未经外部校准；0–100 不表示致病概率、临床风险或药物响应概率。

## 三个层级

**L1：来源内方向统一。** 每个实验原值先按其锁定参考分布求中秩百分位：`100 × (less + 0.5 × equal) / N`。Kato 与 Giacomelli NULL/etoposide 反向，其余维度保持缺陷相关方向。原值保持原始精度；显示舍入不改变计算。Kato 排名比较在 8 位小数处消除浮点尾差。

| 指标 | 参考 N | 原始单位 |
|---|---:|---|
| apo 去稳定化 | 23 个替换 | kcal/mol，纯化 apoDBD，10°C |
| 对 WT 锌 Kd 变化 | 20 个可定量替换 | log10(Kd_mut/Kd_WT)，10°C |
| Kato 八启动子中位活性 | 2,314 个替换 | % WT，酵母 |
| Giacomelli 三个条件 | 每轴 7,448 个替换 | Z-score，A549 |
| Kotler RFS | 4,069 条来源记录 | relative fitness score，H1299 |

锌值优先 direct，否则 model，均与同方法 WT 配对；来源内排名尚包含未经跨方法校准的两类方法。Kotler 为 record-weighted 排名，4,069 条记录对应 2,967 个蛋白替换；同替换不同分值保持来源 accession 和观察范围。

**L2：每一层分别汇总。**

- 结构 `S = (apo percentile + zinc percentile) / 2`。DNA 结合 Kd 原值单列；大量右删失与 WT 未测值不能稳健转换成统一点分，因此本版不参与总指数。
- 功能 `F = (Kato + Giacomelli_LOF + Kotler) / 3`。其中 `Giacomelli_LOF = (NULL/etoposide + NULL/nutlin) / 2`。Kato 使用八启动子中位数，再作为一个实验家族进入 F，不把八个启动子重复计权。
- 显性负性 `D = Giacomelli WT/nutlin percentile`。NCI DNE/LOF 与 ClinGen 策展类别单列，不重复增加实验家族。Giacomelli LOF 与 DNE 条件相关，不能视为两项独立验证。

**L3：统一研究指数。** 默认 `I = 0.25S + 0.50F + 0.25D`。功能优先、三项等权、结构优先三个预设及滑块均可调整。权重是显式的研究假设，不是拟合出的临床模型参数。研究者应报告权重敏感性，不隐藏不利的权重结果。

## 缺失与范围

本次全量审计共有 7,467 个蛋白替换。默认权重下 1,124 个满足显示条件（15.1%），20 个所有计分分量有测量，另有 3 个结构分量部分缺失。其余 1,101 个可显示记录没有本结构实验的 apo/锌值，主区间保留这 25% 权重的不确定性。6,330 个覆盖不足，13 个无可用计分实验。不能把“数据库可查询 7,467 个”表述为“7,467 个均已充分定量”。

- 已知单值视为 `[x,x]`。
- 多记录视为 `[min,max]`，不取中点或平均值冒充测量，不称其为 CI。
- 未覆盖的分量保留未覆盖状态，计算缺失兼容范围时允许 `[0,100]`，而不是填 0。
- 逐层按预设权重传播上下界。范围是可兼容的外包络，不带统计置信概率，也不假设所有极端组合可同时实现。
- 加权覆盖率 = 已量化分量的有效权重之和。范围记录算量化覆盖，但其歧义仍通过宽度保留。覆盖率不是准确率或证据可信概率。
- 总指数加权覆盖达到 60%，且至少两个功能实验家族有值时才显示研究指数。门槛是本版预设的显示规则，尚未生物学校准。其它记录统一显示“尚未定量”，不伪造极端分值。
- 已覆盖项的条件均值范围另列，可用于核对；不能用它替代包含缺失的主区间。

例：若 S 缺失，F=D=80，默认主区间为 60–85、加权覆盖 75%；已覆盖项条件均值为 80。这样不会把结构缺失误判为结构正常。

## 非 missense 与证据适用

HGVS 支持 canonical 蛋白、一/三字母描述、NM_000546.5/.6 编码 SNV、有限 CDS del/dup/ins 与剪接区替换。两版本 CDS 一致，但 3′ 尾序列不同，移码分别翻译。复杂 delins、其它转录本、完整 3′ 归一化与基因组映射不在此静态版支持范围内；明确拒绝，不猜测身份。

无义、移码、剪接区、起始/终止丢失、框内改变、同义均进入统一的“序列机制”路线。受支持范围内可计算序列后果与 PTC；NMD 只是位置性预测。非 missense 没有直接匹配的功能实验时，不借用邻近错义分值，不把 NMD 或外显子位置等同于零蛋白。

NMD 按 PTC 末端距最后外显子接头：>55 nt 支持，<50 nt 不支持，50–55 nt 未决；indel 按变化后的序列调整接头位置。早期 PTC 保留再起始/亚型提示。蛋白输入缺核苷酸身份时不推定 NMD。

来源蛋白身份冲突或 SpliceAI≥0.2 时，原始蛋白实验可展示，但该核苷酸等位基因的机制应用暂停。其它编码查询若剪接未排除，标为条件性应用；蛋白查询仅描述蛋白替换。ClinGen 初步功能代码只展示，不自动应用为完整致病性判定。

用户测量必须有维度、指标、原值、单位、条件、来源，单变异查询下处理。它们不上传、不覆盖公开值；在没有预定义可比分布时不计入综合指数。用户蛋白检测未经过独立核验，不能自动确立阴性对照资格。

## 来源与机制边界

- [NCI TP53 数据下载（IARC 历史资源迁移）](https://tp53.cancer.gov/get_tp53data)，本版锁定 R21。
- [Kato et al., 2003](https://pubmed.ncbi.nlm.nih.gov/12826609/)：八启动子功能实验。
- [Giacomelli et al., 2018](https://www.nature.com/articles/s41588-018-0204-y)：A549 LOF/DNE；第 72 位实验参考差异保留并排除 canonical 匹配。
- [Kotler MAVEdb 原始数据](https://api.mavedb.org/api/v1/score-sets/urn:mavedb:00000059-a-1)：DBD 局部编号经 +101 偏移并核对。
- [Blanden et al., 2020](https://doi.org/10.7554/eLife.61487)：23 个替换 + WT 的 apo/锌实测，及 230 条 DNA 结合记录；正文与补表类别/计数差异保留。
- [ClinGen GN009](https://cspec.genome.network/cspec/ui/svi/svi/GN009)：v2.4 功能策展；重用实验不重复计权。
- [EMBL-EBI AlphaMissense](https://alphafold.ebi.ac.uk/api/prediction/P04637)：7,467 个计算分值，与实验指数分开。
- [UniProt P04637](https://www.uniprot.org/uniprotkb/P04637/entry) 与 RefSeq NM_000546.5/.6：参考序列。

DNA 接触型不能直接判 APR-246 无效：[MQ 原始研究](https://www.nature.com/articles/s41419-018-0463-7)。截断不能直接判无蛋白：[TP53 翻译再起始原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6614817/)。锌缺陷提示 ZMC1 机制研究，不说明临床优于 APR-246。结构分类可以重叠；R282W 不借 R282Q，C176F 不借 C176S。

UMD/p53.fr 独立快照未导入。本版不使用患者 PDO、RNAseq 或临床结局训练/校准。公开分子快照 SHA256 与来源文件版本在 `data/manifest.json`；来源为 v0.3 已核验快照 `df49d0a729ef02bb7661df2bce7b9245fdfbf6b77c88017615a6d324b16b676f`，新增评分规则版本为 research-index-0.4.0。

## 核验与运行

代码无 npm 依赖，GitHub Actions 运行 Node 原生测试，通过后才部署静态 `docs/` 到 GitHub Pages。访问者只需浏览器。数据 gzip 解压后先核对 SHA256；不一致时停止计算。查询和用户补充记录不调用后端 API。

验收包含 7,467 个蛋白参考核对、3,546 个 SNV 与两个转录本的 4,716 个 indel 后果逐项核对、代表变异原始轴/NMD 一致性，以及权重、缺失、歧义、门控、人工输入隔离测试。它们支持软件和数据可复现性，不代替独立生物学验证。
